Le problème
Le motif est une phrase, pas une preuve. Pour trancher, le prof devrait rouvrir le module et chercher le dépôt à la main. « Vu » ne montre rien.
Données dispo
Chaque signalement connaît déjà l'élève, le module (Aletheia · Codex · Fragments), le type, le motif, la source (au rendu / IA) et pointe vers le dépôt. Il « suffit » de l'afficher.

Confirmer (+1 strike) Écarter
Le signal IA ne compte pas tant que tu n'as pas confirmé. « Écarter » = faux positif, l'alerte disparaît sans strike.
Reco format
Sur la page Intégrité : panneau de droite (pas d'overlay). Depuis ailleurs : volet (fiche élève) ou modale (alerte dashboard). Sur mobile : écran plein. Même contenu de preuve partout.
