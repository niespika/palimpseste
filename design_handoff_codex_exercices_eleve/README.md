# design_handoff_codex_exercices_eleve

Handoff design — **Codex · onglet Exercices (côté élève)** : l'écran d'accueil de
l'onglet, et le déroulé d'un exercice (rédiger, choisir, surligner, se juger,
les deux retours).

## Contenu

| Fichier | Rôle |
|---|---|
| `HANDOFF_codex_exercices_eleve.md` | **À lire en premier** : périmètre, jetons, écran par écran, recette |
| `Codex Exercices (élève) - Rendu charte.dc.html` | Les 7 écrans à l'échelle réelle (ordi 1040 + téléphone 390) — référence de couleurs, tailles et libellés |
| `Codex Exercices (élève) - Wireframes.dc.html` | Les structures et les options écartées (tours 1 et 2) |
| `sceaux/codex.png` | Sceau du module, utilisé dans l'en-tête de l'accueil |
| `support.js` | Runtime nécessaire pour ouvrir les deux `.dc.html` |

## Ouvrir les maquettes

Les deux fichiers `.dc.html` s'ouvrent directement dans un navigateur, à côté de
`support.js` et du dossier `sceaux/` (garder l'arborescence de ce dossier).

## Périmètre

Présentation uniquement : aucune Server Action, aucun contrat de données,
aucune règle de doctrine ne change (six temps, « se juger » avant le retour,
aucune note ni lettre ni pourcentage, secret de `indexAttendue`, cibles 44 px).

Côté professeur : hors périmètre.
