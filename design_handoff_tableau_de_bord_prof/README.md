# Handoff — Tableau de bord prof

Dossier prêt pour Claude Code. Tout est relatif : garder la structure telle quelle.

## Contenu
- **`HANDOFF_tableau_de_bord_prof.md`** — les instructions (6 chantiers, rappels charte, responsive, checklist d'acceptation). **Commencer par là.**
- **`Tableau de bord prof Rendu Charte.dc.html`** — cible visuelle hi-fi (tableau de bord, détail de classe, élèves à risque, fiche élève — mobile + ordi). Ouvrir dans un navigateur.
- **`Tableau de bord prof Wireframes.dc.html`** — le « pourquoi » : diagnostic de l'existant + pistes comparées (nav mobile, dashboard) + annotations.
- **`support.js`** — runtime requis par les deux `.dc.html` (chargé en `./support.js`). Ne pas déplacer.
- **`sceaux/`** — sceaux utilisés par la maquette charte.

## ⚠️ Asset à intégrer au codebase
Copier **`sceaux/palimpseste_medaillon.png`** dans **`public/sceaux/`** du projet Next : c'est le sceau **recadré sans le mot dessous**, utilisé comme logo en pastille (cf. Chantier 2). Les autres sceaux (`aletheia/codex/fragments/quazian.png`) sont déjà dans le codebase — ils ne sont ici que pour l'affichage de la maquette.

## Pour visualiser
Ouvrir les `.dc.html` dans un navigateur (double-clic). La structure `./support.js` + `./sceaux/*.png` à côté des fichiers est nécessaire à leur rendu.
