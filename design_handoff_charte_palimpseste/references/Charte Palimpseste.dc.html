PALIMPSESTE

Une encre, un parchemin — et six mondes.

01

Principes

ENCRE SUR PARCHEMIN

Le fond reste un parchemin chaud, le texte une encre sombre. La couleur n'envahit jamais : elle ponctue. C'est ce qui garde l'ensemble lisible et savant.

UN MODULE, UN MONDE

Chaque module porte sa propre palette — comme les ateliers d'une même Renaissance. Ce qui les relie n'est pas la couleur, mais le parchemin, les sceaux gravés et la typographie.

DOSE MODÉRÉE

Le pigment vit dans les bordures, les badges, les têtières et les boutons — pas dans les grands aplats. Un écran reste à dominante parchemin, signé d'une seule couleur.

04

Typographie

quatre rôles
Marque & sceaux — Cinzel
PALIMPSESTE

Capitale lapidaire, en écho aux sceaux. Réservée au nom de marque et aux noms de module, en capitales espacées. Jamais pour de longs textes.

Titres — Cormorant Garamond
L'art de relire

Serif humaniste contrasté, élégant. Pour les titres de page et de section. Sa hampe fine apporte la touche « humanités ».

Corps — EB Garamond

Le palimpseste garde la trace de ce qu'on a effacé ; chaque relecture révèle une couche d'écriture sous la précédente. L'italique sert aux nuances et citations.

Texte courant, paragraphes, consignes. Très lisible, chaleureux.

Interface — Alegreya Sans
Tableaux de bord · badges · dates · chiffres
Semaine 7 — vendredi 18 h · 12 cartes

Sans-serif humaniste pour les interfaces denses, là où le serif fatigue. Garde la chaleur de l'écrit.

05

Les sceaux

pastille teintée
48
84
128

La méthode : le sceau gravé reste noir & blanc, posé sur un disque de la teinte claire du module en mélange « multiply ». Le parchemin du sceau prend la couleur, l'encre reste sombre. Le disque est légèrement plus grand que le sceau pour englober tout le nom.

À faire
  • Teinter le disque dans la couleur du module
  • Garder le sceau N&B, jamais déformé
  • Laisser de l'air autour : le disque enveloppe le nom
À éviter
  • Recolorer l'encre du sceau en plein
  • L'étirer, l'incliner ou le poser sur une image chargée
  • Mélanger deux teintes de module sur un même écran
06

Jetons & intégration

prêt pour Tailwind

Variables CSS à déposer dans globals.css. Le neutre vit dans :root ; chaque module pose sa couleur via [data-module="…"] sur le conteneur de page.

/* Base commune — parchemin & encre */
:root {
  --parchemin:    #F4EFE6;   --surface: #FBF8F1;
  --encre:        #221C16;   --encre-douce: #5A4632;
  --bordure:      #E4DBC9;   --muet: #8A6F4E;
  /* états */
  --ok: #5B6E4A;  --attention: #9A6A2E;  --retard: #A23E2E;
}

/* Un monde par module */
[data-module="palimpseste"]{ --pigment:#5A4632; --teinte:#E8DFCB; --fond:#F4EFE6 }
[data-module="aletheia"]   { --pigment:#2C4A7C; --teinte:#DDE3EC; --fond:#F3ECDD;
                             --or:#B8893B; --minium:#B4452F }
[data-module="fragments"]  { --pigment:#5A6043; --teinte:#E2E3D2; --fond:#EFE9DC;
                             --terracotta:#B26A4A }
[data-module="codex"]      { --pigment:#2E4A3C; --teinte:#DCE6DF; --fond:#F0EADE;
                             --bordeaux:#6E2A2C; --nuit:#28324A }
[data-module="quazian"]    { --pigment:#3E6B8E; --teinte:#DCE6EC; --fond:#F2ECE0;
                             --ocre:#C8993F; --rose:#BE8276 }
[data-module="scriptorium"]{ --pigment:#4A3A28; --teinte:#E6DDC9; --fond:#F0EADE }

/* Polices */
--police-marque: 'Cinzel';            --police-titre: 'Cormorant Garamond';
--police-corps:  'EB Garamond';       --police-ui:    'Alegreya Sans';

Les neutres existants (Tailwind « stone ») restent compatibles : stone-50/100 ≈ parchemin, stone-800/900 ≈ encre. La tuile passe simplement son border-l en var(--pigment).

Verba volant, scripta manent, sapientia permanet.
